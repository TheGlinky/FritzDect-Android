═══════════════════════════════════════════════════════════════

🚀 STEP 1: Repo auf GitHub erstellen
─────────────────────────────────────
1. https://github.com/new
2. Repository name: FritzDect-Android
3. Description: FRITZ!DECT Steckdosen Controller
4. Public ✅
5. Create Repository


📁 STEP 2: Repo lokal clonen
─────────────────────────────
git clone https://github.com/TheGlinky/FritzDect-Android.git
cd FritzDect-Android


📋 STEP 3: Ordnerstruktur erstellen
────────────────────────────────────
mkdir -p .github/workflows
mkdir -p app/src/main/java/com/theglinky/fritzdect
mkdir -p app/src/main/res/values
mkdir -p gradle/wrapper


🔧 STEP 4: Dateien reinkopieren
────────────────────────────────

Root Level (.github/workflows/build-apk.yml):
→ Aus: build-apk.yml
→ Zu: .github/workflows/build-apk.yml

Root Level (settings.gradle.kts):
→ Aus: settings.gradle.kts
→ Zu: settings.gradle.kts

Root Level (build.gradle.kts):
→ Aus: root-build.gradle.kts
→ Zu: build.gradle.kts

App Module (app/build.gradle.kts):
→ Aus: build.gradle.kts (app version)
→ Zu: app/build.gradle.kts

Kotlin Files:
→ MainActivity.kt → app/src/main/java/com/theglinky/fritzdect/
→ FritzViewModel.kt → app/src/main/java/com/theglinky/fritzdect/

XML Files:
→ AndroidManifest.xml → app/src/main/
→ strings.xml → app/src/main/res/values/
→ themes.xml → app/src/main/res/values/

Config Files:
→ .gitignore → .gitignore
→ proguard-rules.pro → app/proguard-rules.pro
→ README.md → README.md


📝 STEP 5: Committen & Pushen
──────────────────────────────
git add .
git commit -m "Initial commit: FRITZ!DECT Android App"
git push origin main


⏱️ STEP 6: Warten auf GitHub Actions Build
────────────────────────────────────────────
1. GitHub.com → Dein Repo → Actions Tab
2. "Build APK" Workflow sollte laufen (orange)
3. Warten bis grün (✅) = Build successful
4. Artifacts Tab → Download APK


📱 STEP 7: APK auf Handy laden & installieren
──────────────────────────────────────────────
1. APK downloaden (app-debug.apk)
2. Auf Handy via Dateimanager installieren
3. App öffnen → FRITZ!Box IP eingeben → GO! 🚀


═══════════════════════════════════════════════════════════════

TIPPS:
------
- Alle Dateien genau kopieren (Typos = Build Fehler!)
- build.gradle.kts zweimal vorhanden: 1x Root, 1x app/
- .github/workflows/ MUSS sein für Auto-Build
- Actions Tab = wo du deine APKs runterlädst


CHANGES MACHEN:
---------------
git pull origin main          # Latest Code holen
nano app/src/main/.../File.kt # Datei editieren
git add .
git commit -m "Deine Message"
git push origin main
→ Automatischer Build startet!
